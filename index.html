Для новичков

Как пользоваться калькулятором:

  1. Выберите предмет в шаге 1 — появится список доступных для него чар.
  2. Нажмите на чары в шаге 2 — они добавятся в «Выбранные книги». Повторный клик по тому же чару повышает его уровень.
  3. Проверьте список в шаге 3: там можно изменить уровень чара или удалить его. Кнопка 🗑️ Очистить удаляет все чары сразу.
  4. Нажмите «Рассчитать стоимость» — появится пошаговый расчёт с ценой каждой операции.

💡 Если стоимость шага превышает 39 уровней, он подсветится красным — такое зачарование невозможно в режиме выживания.

Для опытных игроков

Основной функционал

  1. Шаг 1. Выберите предмет. При смене предмета ранее выбранные чары сбрасываются.
  2. Шаг 2. Нажимайте на чары — они добавляются в список. Повторный клик повышает уровень до максимума. Несовместимые чары автоматически блокируются (серые и зачёркнутые).
  3. Шаг 3. Добавление своих (кастомных) чар — если нужного чара нет в списке.
  4. Шаг 4. Полная таблица выбранных чар: можно править название, уровень, множитель, максимальный уровень, группу и источник (книга / предмет).
  5. Шаг 5. Дополнительные операции и штраф предмета.

Дополнительный функционал (шаг 5)

  • 🔧 Ремонт предмета — включает операцию ремонта, добавляет +2 уровня к финальной стоимости.
  • ✏️ Переименование — добавляет +1 уровень к стоимости.
  • 🛠️ Прошлых зачарований (n) — сколько раз предмет уже использовался в наковальне. Влияет на штраф к стоимости: штраф = 2ⁿ − 1. Если предмет новый, оставьте 0.

Кастомные чары (шаг 3)

Используются, когда нужного зачарования нет в стандартном списке. Заполните поля:

  • Название — название чара.
  • Ур. — уровень зачарования.
  • Множ. — множитель стоимости. Если не знаете — оставьте пустым, калькулятор возьмёт значение автоматически.
  • Макс. — максимальный уровень (пусто = 99).
  • Группа — метка несовместимости. Чары с одинаковой группой не могут стоять на одном предмете.
  • 📖 Книга / ⚔️ Предмет — источник чара. Для книги множитель делится на 2, для предмета используется полный множитель.

Как определить множитель чара

Если в вашем датапаке или моде множитель неизвестен, его можно вычислить экспериментально:

Множитель = Стоимость на наковальне / Уровень зачарования

Пример: книга с чаром «Life Leech 2» на наковальне стоит 6 уровней. Множитель = 6 / 2 = 3. Введите 3 в поле «Множ.».

Штраф за прошлые использования

Стоимость переименования предмета в наковальне (без смены названия) равна 2ⁿ, где n — число прошлых операций. Это самый простой способ узнать штраф уже существующего предмета:

Группы несовместимых чар

Чары одной группы нельзя объединить на одном предмете. При попытке слияния одно из них будет отброшено (и добавит +1 к стоимости операции):

Группа Описание
damage Все чары, увеличивающие урон в ближнем бою (аналоги Sharpness, Smite)
protection Все виды защитных чар на броню
mining Чары, влияющие на добычу блоков (аналоги Fortune, Silk Touch)
boots Чары на ботинки, конфликтующие между собой (аналоги Depth Strider, Frost Walker)
trident Чары для трезубца (аналоги Riptide, Loyalty)
bow Чары для лука (аналоги Infinity, Mending)
crossbow Чары для арбалета (аналоги Multishot, Piercing)
